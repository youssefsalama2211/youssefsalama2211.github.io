      Set up the workflow

      1. In n8n, import nour-workflow.json (Workflows → Import from file).
      2. Create a Header Auth credential named Nour reception key with name X-Nour-Key and a long random value. Select it on the Reception In node.
      3. Activate the workflow. Conversations and bookings are stored only in production runs, so test with the production URL.
      4. For AI replies: create a Header Auth credential with name x-api-key and your Anthropic API key, select it on AI Reply (Claude), then set AI_ENABLED: true at the top of Understand & Retrieve.
      5. For alerts: paste a Discord webhook URL into Notify Reception and set NOTIFY_ENABLED: true.
      6. Edit the clinic details, prices and answers in the KB list at the top of Understand & Retrieve.

      A page hosted on another site cannot reach n8n on your own computer. To use live mode with a local n8n, open the downloaded nour-demo.html file on the same machine.
