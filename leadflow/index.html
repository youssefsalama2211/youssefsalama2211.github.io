Set up the workflow

  1. Import leadflow-workflow.json in n8n.
  2. Create a Header Auth credential with name X-LeadFlow-Key and a long random value. Select it on Dashboard In.
  3. Activate the workflow. Leads are stored only in production runs.
  4. Optional, each with its own switch at the top of Validate & Score: Google Sheets (SHEETS_ENABLED), SMTP auto-reply (EMAIL_ENABLED), Slack hot-lead alerts (SLACK_ENABLED), Claude advisor (AI_ENABLED).
  5. Weekly report and the hourly call-back check have their own switches at the top of Build Weekly Report and SLA Check.
  6. Change scoring, service area, sales reps and estimate assumptions in the same settings block.

A page hosted on another site cannot reach n8n on your own computer. For a local n8n, open the downloaded leadflow-demo.html on the same machine.
